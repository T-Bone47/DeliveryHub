# Page Specification: Admin Agents Management (`admin-agents.md`)

> **Role:** Operations Administrator
> **Route:** `/admin/agents`
> **Goal:** Courier fleet roster, operational capacity tracking, and status monitoring.

---

## 1. Information Hierarchy & Layout

1. **Page Header:**
   - Title: `Courier Fleet Roster`
   - Subtitle: `Active delivery agents, vehicle fleet, and real-time availability.`
   - Action: `[ + Add Agent ]`

2. **Fleet Summary Indicators:**
   - Quick counters for Available, Busy, and Offline couriers.

3. **Agent Roster Table / Grid:**
   - Columns: `Agent Name`, `Agent Code` (Monospace), `Vehicle Type`, `Operational Status` (Badge with indicator), `Active Deliveries`, `Completed`, `Rating` (Star score), `Actions`.
   - Direct link to `[ Manage ]` agent profile and zones.
